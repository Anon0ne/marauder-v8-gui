Marauder V8 Control 0.4.2b — Windows

PORTABLE EXE
Extract the Windows ZIP and launch MarauderV8-Control.exe. No Python required.

AUTOMATED SOURCE BUILD
Double-click BUILD_AND_INSTALL.cmd. It checks for Python 3.10-3.13 first, installs Python 3.12 automatically if missing (winget or verified official installer), builds the executable, and creates Desktop and Start Menu shortcuts. Internet access is required for Python and dependencies. No administrator privileges are normally required.

The installer automatically checks and installs missing or outdated Python packages (pyserial, esptool, PyInstaller and their dependencies), validates package compatibility, then builds the EXE. Internet access required for missing packages.

MANUAL SOURCE INSTALL
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe marauder_workspace.py

Optional NPU setup: SETUP_NPU.cmd, then RUN_NPU.cmd. See NPU_SETUP.md for experimental limitations.
