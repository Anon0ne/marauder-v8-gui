Marauder V8 Control GUI v0.3.2 - Windows

MANUAL INSTALL (standalone EXE)
Extract MarauderV8-v0.3.2-Windows.zip and run MarauderV8-Control.exe.
Python is not required. Create a shortcut manually if desired.

AUTOMATED INSTALL / BUILD FROM SOURCE
Double-click BUILD_AND_INSTALL.cmd in the extracted folder.
The script locates Python 3.10-3.13, installs Python 3.12 if missing,
creates an isolated build environment, installs required dependencies,
checks compatibility, builds the EXE, and creates Desktop and Start Menu shortcuts.
Internet access is required for missing Python, dependencies, and build tools.
The app is installed under %LOCALAPPDATA%\Programs\MarauderV8-Control.

MANUAL RUN FROM SOURCE
Install Python 3.10-3.13 from python.org with Tkinter and pip enabled.
Open PowerShell in the extracted source folder and run:
  py -3 -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe marauder_gui.py

MANUAL EXE BUILD
After the manual source setup, run:
  .\.venv\Scripts\python.exe -m pip install "pyinstaller>=6.0,<7"
  .\.venv\Scripts\python.exe -m PyInstaller --noconfirm --clean MarauderV8-Control.spec
The executable is created at dist\MarauderV8-Control.exe.
