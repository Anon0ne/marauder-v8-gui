# Community code of conduct

This project welcomes people with different backgrounds and levels of experience. Participants must communicate respectfully in issues, pull requests, reviews, and other project spaces.

## Expected conduct

- Discuss ideas and code constructively; explain disagreements without personal attacks.
- Respect privacy, consent, accessibility needs, and different perspectives.
- Give useful feedback and accept corrections in good faith.
- Keep testing within systems and networks you own or have permission to assess.

## Unacceptable conduct

Harassment, threats, discrimination, sexualized conduct, doxxing, impersonation, repeated personal attacks, and deliberate disclosure of another person's private information are not welcome. Do not use project spaces to coordinate unauthorized attacks or share stolen credentials.

## Reporting

Contact maintainer [Anon0ne](https://github.com/Anon0ne) privately at **justin@bizhostnc.com**. Describe what happened, link relevant project content where possible, and identify any immediate privacy concerns. Report security vulnerabilities using [SECURITY.md](SECURITY.md) instead of a public issue.

## Enforcement

The maintainer may edit or remove inappropriate content, request a behavior change, restrict participation, or block an account. Responses should be proportionate to the conduct and its impact. Reports will be handled with discretion; absolute confidentiality cannot be guaranteed. A reporter may request a review of an enforcement decision through the same private contact.

This policy applies in project spaces and when someone represents the project elsewhere.
