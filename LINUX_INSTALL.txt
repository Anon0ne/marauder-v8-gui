Marauder V8 Control GUI - Linux

DEB PACKAGE (NO PYTHON REQUIRED, amd64)
Install the self-contained .deb - it bundles its own Python runtime and
esptool, so no system Python, pip or venv is needed:
  sudo apt install ./specter-v8_<version>_amd64.deb
Then launch it from your application menu ("Specter V8 Control") or run:
  specter-v8
Serial access to the device needs your user in the "dialout" group:
  sudo usermod -aG dialout "$USER"      # then log out and back in
Remove with:  sudo apt remove specter-v8
Build the .deb yourself from a source checkout (needs pyinstaller + dpkg-deb):
  BUILD=1 tools/build_deb.sh            # output: dist/specter-v8_<version>_amd64.deb

AUTOMATED SETUP AND LAUNCH (Python source distribution)
Extract the Linux ZIP, open a terminal in that folder, and run:
  bash INSTALL_AND_RUN.sh
The launcher creates an isolated virtual environment and installs dependencies.
On Debian/Ubuntu it installs missing Python, Tkinter, or venv packages using sudo apt-get.
On other distributions, install these prerequisites using your package manager first.
Internet access is required when installing packages.

MANUAL SETUP (Debian/Ubuntu)
  sudo apt-get install python3 python3-tk python3-venv
  python3 -m venv .venv
  .venv/bin/python -m pip install -r requirements.txt
  .venv/bin/python marauder_workspace.py
Use Python 3.10-3.14. Other distributions use their own package manager.
Kali note: the repo is public, so you can also `git clone https://github.com/Anon0ne/marauder-v8-gui.git` and run bash INSTALL_AND_RUN.sh for the latest source.

If serial access is denied on Debian/Ubuntu:
  sudo usermod -aG dialout "$USER"
Log out and back in afterward. Other distributions may use a different device group.

This is a source distribution, not a standalone Linux executable.
